# Diseñador de Riego V2 — Web/PWA

Aplicación web progresiva para Android.

## Instalación
1. Publicar esta carpeta en un sitio HTTPS.
2. Abrir la dirección en Chrome Android.
3. Elegir "Añadir a pantalla de inicio" / "Instalar aplicación".
4. La app funciona en modo independiente y guarda el proyecto exportándolo como JSON.

## Incluye
- Parcelas irregulares.
- Cuatro tipos de emisores.
- Sectores.
- Caudal y presión.
- Estimación de cobertura.
- Tuberías y diámetro preliminar.
- Lista de materiales.
- Exportación del proyecto a JSON.

Para una instalación real, el cálculo hidráulico debe verificarse profesionalmente.
